# Windows icon assets

`icon.ico` is the canonical Windows application icon used by Tauri/NSIS. Keep it in the repository because `tauri-build` requires a Windows resource icon during `cargo check`/build on Windows.

Visual direction: Windows 11 / Fluent blue tile with a white document glyph, consistent with the locked SolYan PDF desktop visual language in `docs/WINDOWS-DESKTOP-UX-LOCK.md`.
