# Whole Word Auto Redact — acceptance cases

These cases define the intended matcher behavior for review and future CI extension.

| Haystack | Needle | Whole Word | Expected |
|---|---|---:|---:|
| `an toàn` | `an` | true | match |
| `banana` | `an` | true | no match |
| `mã số` | `mã` | true | match |
| `mã_số` | `mã` | true | no match |
| `ắ` (NFC) | `ắ` (decomposed) | true | match after NFC normalization |
| `ABC-842` | `ABC` | true | match |
| `ABC842` | `ABC` | true | no match |

The production matcher still redacts the entire PDF.js text-run containing an accepted occurrence; it does not calculate a sub-run rectangle.
