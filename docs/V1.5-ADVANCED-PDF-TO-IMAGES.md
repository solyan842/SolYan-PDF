# V1.5 — Advanced PDF → Images

## Gap

The original SolYan PDF → Images tool rendered every page at a raw scale factor, offered PNG/JPEG only, and always returned a ZIP. Maintained Stirling-PDF exposes explicit DPI, selected pages, color mode, annotation inclusion and single/multiple output. Its `single` mode vertically combines all rendered pages into one large image.

## OSS-first decision

Keep the conversion browser-local and reuse the already-shipped `pdfjs-dist`, Canvas and JSZip stack. No backend renderer, Python/OpenCV path, native image library or new npm dependency is added.

## Accepted behavior

- page selection uses the shared `parsePages()` syntax and preserves requested order;
- DPI choices: 96, 150, 200, 300; default 150 DPI;
- formats: PNG, JPEG, WebP;
- color modes: Color, Greyscale, Black & White;
- annotation rendering can be enabled/disabled through PDF.js `AnnotationMode`;
- Multiple output writes one file per physical PDF page into a ZIP;
- Single output vertically combines selected pages in order into one image whose width is the widest rendered page;
- JPEG/WebP use Canvas quality 0.92;
- a white page background is used so JPEG/B&W output does not inherit transparent pixels.

## WebP boundary

Canvas WebP support is browser-dependent. After `toBlob(..., "image/webp")`, SolYan verifies that the returned blob is actually `image/webp`. Unsupported browsers fail clearly and direct the user to PNG/JPEG instead of writing non-WebP bytes with a `.webp` extension.

TIFF is intentionally not added: browser Canvas has no native TIFF encoder and parity would require another codec/runtime dependency solely for this lane.

## Color conversion

Greyscale uses luminance:

`0.2126 R + 0.7152 G + 0.0722 B`

Black & White uses the same luminance with a threshold of 128. The alpha channel is forced opaque after conversion.

## Resource limits

- input PDF: 100 MB maximum;
- selected pages: 200 maximum;
- raster per page: 25,000,000 pixels maximum;
- total render budget: 80,000,000 pixels maximum;
- Single vertical composite: 60,000,000 pixels maximum;
- Single canvas width/height: 16,384 pixels maximum per dimension.

The tool preflights all selected page dimensions before rendering. Single mode therefore rejects oversized composites before allocating the combined canvas.

## Annotation boundary

The toggle controls PDF.js page-render annotation inclusion. Only annotations/widgets that PDF.js can paint into the page render are represented; SolYan does not claim to emulate every interactive annotation layer or editor state.
