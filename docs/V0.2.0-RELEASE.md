# SolYan PDF v0.2.0 Release

## Scope

SolYan PDF v0.2.0 packages the provider-backed capabilities added after v0.1.9 while preserving the existing PDF engine, OCR, Office-conversion and security gates.

### Included

- V1.7 Cloud Storage connectors: Google Drive + OneDrive through the provider-neutral storage contract.
- V1.8 WebDAV storage adapter with server-side credentials, opaque browser session, PDF-only browse/download/upload/replace and explicit no-silent-overwrite behavior.
- Existing V1.6 local-first PDF translation release scope remains intact.
- Existing PDF -> Office V1 gate remains locked at 27 cases / 68 source pages.

V1.8 PR #132 exact head `5eb44e866268677a628b05e3ef76d094714510f6` passed all pull-request-triggered workflows, including Backend CI, Frontend CI, Cloud Storage CI, WebDAV Storage CI and Deployment CI.

The post-merge `main` run set contained 28 workflow runs for that exact merge commit. At release preparation time all runs had completed; no queued/in-progress, failed or cancelled run remained.

Release packaging synchronizes the FastAPI version, `frontend/package.json`, and `frontend/package-lock.json` to `0.2.0`. The one-shot lock synchronization workflow removed itself from the release branch before final CI/merge, so no release-only helper workflow remains in the product tree.

## Deployment boundaries

- Google Drive and OneDrive require operator-owned OAuth application configuration for live provider use.
- WebDAV requires operator-owned `WEBDAV_BASE_URL`, username/password and TLS policy configuration.
- Real provider credentials are not build/CI prerequisites and remain outside browser storage.
- The default Docker Compose deployment is covered by Deployment CI: compose validation, complete stack build, health wait, backend health smoke and frontend smoke.
- Multi-party / remote signing and AI summarization remain separate product/provider decisions and are not blockers for this release.

## Version

Release version: `0.2.0` / tag `v0.2.0`.

This is a minor-version release because the provider-backed storage surface expands materially beyond v0.1.9 rather than being a small patch to the translation release.
